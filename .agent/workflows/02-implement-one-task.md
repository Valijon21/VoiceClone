# Workflow 02 — Bitta taskni bajarish

1. `tasks/ROADMAP.md` ichidan foydalanuvchi ko‘rsatgan task ID’ni top.
2. Taskning old shartlari va acceptance criteria’larini o‘qi.
3. Kod bazasini ko‘zdan kechir; mavjud implementatsiyani buzma.
4. Rejani ko‘rsat, keyin faqat shu task doirasida ishlagin.
5. Kod, test va kerakli hujjatlarni yangila.
6. Tegishli testlarni ishga tushir; testlar ishlamasa, haqiqiy sababini yoz.
7. Taskni faqat acceptance criteria dalil bilan bajarilganda `DONE` deb belgilagin.
8. Yakuniy javobda o‘zgargan fayllar, test natijalari, qolgan risklar va keyingi task ID’larini ber.
